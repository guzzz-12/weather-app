**Descripción del Proyecto**
==========================

Aplicación web para verificar las condiciones actuales del tiempo y el pronóstico de los próximos 5 días en una ubicación determinada. Además del estado del tiempo, muestra otras variables meteorológicas, como calidad del aire, humedad relativa, presión atmosférica, visibilidad, entre otras. Cuenta con mapa integrado con funcionalidad de direct geocoding para buscar ubicaciones por nombre en el mapa y verificar las condiciones del tiempo en dicha ubicación. Desarrollado en Next.js, TypeScript, TailwindCSS y Mapbox.

**Tecnologías Utilizadas**
--------------------------

* **Desarrollo Frontend:**
  * **Next.js (App Router y TypeScript):** Para la creación de la interfaz de usuario completamente responsive.
  * **Shadcn UI y Tailwind CSS:** Para la creación de componentes enfocados tanto en la flexibilidad como en la accesibilidad web.
  * **Mapbox:** Para el mapa integrado con direct geocoding.
